# 🌱 SkillShare  
**Exchange skills. Empower each other. Learn and teach together.**

🔗 **Live Demo:** https://skill-share-delta.vercel.app/

---

## 🚀 Overview

**SkillShare** is a peer-to-peer skill exchange platform designed to help learners and mentors connect through meaningful collaboration.  
Instead of traditional courses, SkillShare enables **direct skill swaps** — you teach what you know and learn what you need.

An **AI-powered matching system** intelligently connects users with the most compatible partners based on shared interests, offered skills, and learning goals — so you can grow faster, together.

---

## ✨ Key Features

### 👤 Profile Management
- Create a personalized profile with:
  - Bio
  - Skills you offer
  - Skills you want to learn
  - Interests and preferences

### 🤖 AI Skill Matching
- Vector-based similarity matching
- Ranks peers by real compatibility
- Transparent and practical scoring logic

### 🔄 Requests & Peer Network
- Send and accept skill swap requests
- Build and manage your learning network

### 💬 Real-Time Messaging
- Live chat between peers
- Smart date labels: **Today / Yesterday / Weekday**
- Clean, conversation-focused UI

### 📅 Session Scheduling
- Share session plans directly inside chat
- Keeps learning organized and actionable

### 👥 Communities
- Create or join topic-based communities
- Community creators are automatically assigned as admins

### 📝 Posts & Engagement
- Share updates with image support
- Optional pending-approval workflow
- Persistent comment threads with show/hide toggle

### ❤️ Reactions
- Professional multi-icon reactions:
  - Like
  - Love
  - Celebrate
  - Insightful
  - Funny

### 🔔 Notifications
- Real-time alerts for:
  - Requests
  - Messages
  - Community activity

### 🔐 Secure Authentication
- JWT-based authentication
- Protected routes for sensitive actions
- Session-safe access control

## ⚡ Getting Started (Quick Start)

1. Open the live app 👉 https://skill-share-delta.vercel.app/
2. Sign up and complete your profile
3. Add skills you offer and skills you want to learn
4. Visit **AI Match** to discover compatible peers
5. Start chatting, scheduling sessions, and sharing knowledge 🚀
