SkillShare

- Exchange skills. Empower each other. Learn and teach together.
Live Deploy

- https://skill-share-delta.vercel.app/
Overview

- Find peers who share your passions and connect for skill swaps. An AI matcher surfaces the most compatible partners based on your profile, so you can focus on growing faster.
Functionalities

- Profile setup: Bio, skills you have, skills you want, interests
- AI Match: Vector-based similarity to rank best partners
- Requests & peers: Send/accept skill swap requests; build your peer network
- Messaging: Real-time chat with “Today/Yesterday/Weekday” labels
- Scheduling: Drop session plans right inside chat
- Communities: Create or join topic groups; creators are auto-admins
- Posts: Share updates with images and pending-approval flow (optional)
- Reactions: Professional multi-icon reactions (Like, Love, Celebrate, Insightful, Funny)
- Comments: Persistent threads with show/hide
- Notifications: Request updates and activity alerts
- Secure auth: JWT-based sessions with protected routes
Why It’s Different

- Practical AI matching: Simple, transparent scoring focused on real collaboration
- Clean, consistent UI: A calming, professional design with thoughtful details
- Built for skill sharing: Every feature reinforces teaching and learning
Tech Stack

- Frontend: React + Vite, Tailwind, Lucide
- Backend: Node.js/Express, MongoDB, JWT auth
Getting Started (Quick)

- Just open the live link above, sign up, fill your profile, and check AI Match to discover partners.
